## Getting Started

Clone the repository:

```bash
git clone https://github.com/gyr0byte/genai-langchain.git
cd genai-langchain
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On macOS/Linux:

```bash
source .venv/bin/activate
```

On Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add the API keys needed by your projects.

## Security Note

Never commit `.env`, API keys, tokens, or other secrets. The repository ignores local environment files, and `.env.example` contains placeholder names only.
